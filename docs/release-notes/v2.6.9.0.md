# OmniConsoleMod v2.6.9.0

A feature release: gamepad mappings can now reach apps that run as
administrator, your platform can be launched as administrator, and the
platform selector now lists the other home apps Windows offers.

## Updating

Already on **2.6.0.0 or later**? The in-app updater will pick this up
automatically (Settings → ☰ → Advanced). No reinstall needed.

Coming from an older build signed by a different publisher? Do a one-time fresh
install: download `OmniConsoleMod_2.6.9.0_x64.zip` below, extract, and run
`Install.bat`.

## What's changed

- **New: Administrator App Support.** Windows blocks input sent to apps that
  run as administrator, so until now your mappings stopped working the moment
  such an app was on screen. Turn it on in Settings → Advanced → Gamepad Input
  → Administrator App Support → **Install**.
  - Asks for administrator approval once. Your Windows account needs
    administrator rights.
  - After future OmniConsoleMod updates it asks to be updated too, which takes
    one more approval.
  - If an administrator app is on screen and your mappings can't reach it,
    Settings and the OmniCharm widget tell you so instead of leaving you
    guessing.
  - Can be removed at any time from the same place.
- **New: Run platform as administrator.** Settings → Advanced → Platform
  launch. Off by default.
  - With Administrator App Support installed, Store apps and programs installed
    under Program Files start as administrator **without a UAC prompt**.
  - Programs in a personal folder (for example `C:\Games`) still show a UAC
    prompt on every launch, which can't be answered with a controller.
    Cancelling the prompt cancels the launch.
  - Has no effect on platforms Windows starts itself, such as the Xbox app. The
    setting tells you when that's the case.
- **New: Home apps in the platform selector.** Every app Windows offers under
  Settings → Gaming → Full screen experience → Choose home app (AnyFSE, for
  example) now shows up as a platform card, so a third-party shell stays
  reachable after OmniConsoleMod takes over the home app slot.
  - Two extra cards: **None**, and **Xbox App (windows native)** to hand the
    home role back to Xbox.
  - Picking a home app card only changes Windows' home app. Your default
    platform choice is kept.
- **New: Gamepad cursor conflict warning.** When another app moves the pointer
  with your controller while Mouse Mode does too, most likely Game Bar's
  Gamepad Cursor, the Gamepad Mapping page warns you under the Mouse Mode
  switch. Running both means doubled cursor speed and scrolling that fights
  itself. Steam Input, DS4Windows and Armoury Crate desktop mode trigger the
  same warning.
- **Improved: Layered profile editor.** Layered profiles now show one layer at
  a time behind **Layer 1 / Layer 2** tabs. Switch with **LB / RB**. Each
  button group header says which layer you're editing.
- **Fixed: Gaming profile's Layered Mode toggle** now stays the way you set it
  instead of turning itself back on.
- **Fixed: LB / RB sounds.** They no longer play a "success" sound when the
  press didn't change anything.
- **Smoother navigation** in Settings when debug logging is off.
- **Diagnostics:** the OmniCharm widget now writes to the same debug log as
  the app when debug logging is on (Settings → Troubleshoot).
- **Under the hood:** upgraded to .NET 10. The updater now picks release files
  by version rather than by file name, so future releases can rename them
  without breaking in-app updates.

## Requirements

Windows 11 with the Full Handheld edition of Xbox Mode (FSE). See the
[README](https://github.com/red-Geck0/OmniConsoleMod#readme) for details.
